Anonymous on both sides

Clients choose any name they like. Therapists use a display name too — nobody's identity is shared.

Nothing is stored

Conversations live in memory only and disappear when the server restarts. No accounts, no history.

Real-time chat

Messages arrive instantly on both sides, so the conversation feels natural.

Theripo is a student project and not an emergency service. If you are in danger, call your local emergency number or 988 (US Suicide & Crisis Lifeline).
